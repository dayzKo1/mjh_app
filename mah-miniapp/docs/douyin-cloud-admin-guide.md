# 抖音小游戏云后台管理指南

## 一、抖音云开发后台入口

1. 登录 [抖音开发者平台](https://developer.open-douyin.com/)
2. 进入小程序管理 → 选择对应小游戏
3. 点击「云开发」进入后台

## 二、云函数管理

### 2.1 查看云函数

- 路径：云开发 → 云函数
- 可查看所有已部署的云函数列表
- 支持查看函数代码、配置、日志

### 2.2 部署云函数

**方式一：开发者工具上传**
```bash
# 在项目根目录执行
tt-cli cloudfunctions upload --function user
tt-cli cloudfunctions upload --function game
```

**方式二：后台手动上传**
1. 云函数 → 点击「上传」
2. 选择本地函数目录（需包含 index.js 和 package.json）
3. 等待上传完成

### 2.3 云函数日志查看

- 云函数 → 选择函数 → 点击「日志」
- 可按时间范围筛选
- 支持关键词搜索
- 查看错误堆栈和执行时间

### 2.4 环境变量配置

用于存储敏感信息（API密钥等）：

1. 云函数 → 选择函数 → 点击「配置」
2. 添加环境变量：
   - `ADS_ENABLED`: `true` / `false`
   - `AD_UNIT_REWARDED`: 激励视频广告位ID
   - `AD_UNIT_BANNER`: Banner广告位ID
3. 保存后需重新部署生效

## 三、数据库管理

### 3.1 创建集合

当前项目需要的集合：
- `users` - 用户信息
- `records` - 游戏记录
- `levelProgress` - 关卡进度

创建步骤：
1. 云开发 → 数据库 → 点击「添加集合」
2. 输入集合名称
3. 配置权限规则（建议：仅创建者可读写）

### 3.2 数据操作

- **查询数据**：支持 JSON 查询语法
- **添加数据**：手动添加单条记录
- **导入数据**：批量导入 JSON/CSV
- **导出数据**：导出为 JSON 格式

### 3.3 索引优化

为高频查询字段创建索引：
```javascript
// users 集合 - userId 字段
db.collection('users').createIndex({ userId: 1 })

// records 集合 - userId + score 复合索引
db.collection('records').createIndex({ userId: 1, score: -1 })
```

## 四、广告位管理

### 4.1 创建广告位

1. 小程序管理 → 流量主 → 广告位管理
2. 点击「新建广告位」
3. 选择广告类型：
   - **激励视频广告**（推荐）：用户看广告获得道具/复活
   - **Banner广告**：底部横幅
   - **插屏广告**：过关时弹出

### 4.2 广告位ID配置

获取广告位ID后，在项目配置：

**方式一：环境变量（推荐）**
在云函数环境变量中设置：
- `AD_UNIT_REWARDED`: 激励视频ID
- `AD_UNIT_BANNER`: Banner ID

**方式二：代码配置**
修改 `utils/ad.js`：
```javascript
const AD_UNITS = {
  rewarded: '实际广告位ID',
  banner: '实际广告位ID',
};
```

### 4.3 广告数据查看

流量主 → 数据报表：
- 查看广告展示量、点击率
- 查看收益数据
- 按日期筛选

## 五、版本管理

### 5.1 发布版本

1. 开发者工具 → 点击「上传」
2. 填写版本号和更新说明
3. 后台审核管理 → 提交审核
4. 审核通过后点击「发布」

### 5.2 版本回滚

后台 → 版本管理 → 选择历史版本 → 点击「回滚」

## 六、数据分析

### 6.1 用户分析

数据分析 → 用户分析：
- 新增用户数
- 活跃用户数
- 用户留存率
- 用户画像（地域、设备）

### 6.2 游戏数据

自定义上报数据查看：
- 关卡通过率
- 道具使用统计
- 广告触发次数

## 七、常见问题

### Q1: 云函数调用失败

**排查步骤**：
1. 检查云函数日志是否有错误
2. 确认环境变量配置正确
3. 检查网络请求权限是否开通

### Q2: 广告不展示

**排查步骤**：
1. 确认广告位ID配置正确
2. 检查是否在测试环境（测试环境广告可能不展示）
3. 检查用户是否触发广告条件

### Q3: 数据库读写失败

**排查步骤**：
1. 检查集合权限规则
2. 确认字段名称匹配
3. 检查数据大小是否超限
