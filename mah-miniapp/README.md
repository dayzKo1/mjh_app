# 麻将消消乐 - 抖音小游戏横屏版

## 项目简介

基于抖音小程序平台的麻将牌三消游戏（羊了个羊玩法），横屏布局，支持广告复活和道具系统。

## 游戏特性

- **横屏布局**: 原生支持 `pageOrientation: "landscape"`
- **倒计时进度条**: 不显示具体时间，每次操作增加进度，时间结束失败
- **关卡解锁**: 通关上一关解锁下一关（非积分解锁）
- **道具系统**: 回退、寻找、炸弹三种道具
- **广告机制**: 
  - 倒计时结束时看广告加时间
  - 游戏失败看广告复活
  - 道具次数用完看广告获取

## 开发指南

### 环境要求

- 抖音小程序开发者工具
- 抖音云开发环境

### 配置步骤

1. 在 `project.config.json` 中填写 AppID
2. 在抖音云后台创建云函数 `user`、`game`
3. 配置广告位ID（见 `docs/douyin-cloud-admin-guide.md`）

### 广告位配置

修改 `utils/ad.js` 或在云函数环境变量设置：
```javascript
const AD_UNITS = {
  rewarded: '你的激励视频广告位ID',
};
```
